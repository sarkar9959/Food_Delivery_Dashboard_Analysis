# Food Delivery Dashboard Analysis

## Project Overview

An interactive Food Delivery Dashboard built using Microsoft Excel and Power Query to analyze sales performance, order trends, customer insights, and delivery operations.

The dashboard provides key business insights through KPIs, charts, and interactive filters to support data-driven decision-making.

## Tools & Technologies

* **Microsoft Excel** – Dashboard development and data visualization
* **Power Query** – Data cleaning, transformation, and preparation
* **Pivot Tables & Pivot Charts** – Data analysis and reporting
* **Slicers** – Interactive dashboard filtering

## Key KPIs

* Total Orders
* Gross Sales
* Net Sales
* Total Customers
* Delivered Orders
* Cancelled Orders
* Cancellation Rate
* Average Order Value
* Average Delivery Time
* Average Delivery Distance

## Dashboard Features

* Sales and order analysis by city
* Gross sales and net sales comparison
* Item-wise sales and order performance
* Cancelled orders analysis by food item
* Delivery status distribution
* Delivery performance by vehicle type
* Interactive filters for dates, items, and cities

## Business Objectives

* Monitor overall sales and order performance.
* Identify sales trends across different cities and food items.
* Understand order cancellations and delivery status.
* Compare delivery performance across vehicle types.
* Support operational decisions using key business metrics.
